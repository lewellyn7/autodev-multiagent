## 认证与授权

- FastAPI 依赖 `get_current_user()` 验证 session_token
- Cookie 或 Header `X-Session-Token` 传递
- 未登录返回 401

## 输入验证

- URLValidator 白名单机制
- InputSanitizer 清理
- 参数类型检查（Pydantic BaseModel）

## 高危风险

1. **时序攻击** — 密码比较使用 `==` 而非 `hmac.compare_digest`
2. **CSRF 绕过** — 无 session 的请求直接放行 POST
3. **信息泄露** — traceback 打印可能暴露敏感路径
4. **密钥暴露** — docker-compose 中硬编码 API Key

## 建议

1. 修复 H-1: 使用 `hmac.compare_digest` 比较密码哈希
2. 修复 H-2: 匿名 POST 请求需要 CSRF 验证
3. 修复 H-3: 使用 `tempfile.mkdtemp(prefix="tender_", mode=0o700)`
4. 清理硬编码密钥，迁移到 .env 或 Docker secrets
5. 审计日志已完善，建议定期巡检
