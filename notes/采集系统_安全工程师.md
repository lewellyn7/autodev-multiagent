### ⚠️ 当前安全风险（按优先级）

**🔴 高（已存在但被设计规避）**

1. **DEPLOYMENT_MODE=self + DEFAULT_ADMIN_PASSWORD=lewellyn**
   - 设计上 self 模式仅供自用，但若误部署到公网 = 完全裸奔
   - 缓解：未在公网暴露（端口未对外），无 Caddy/Nginx 反代
   - **建议**：加 startup 断言，若 `DEBUG=false` 且 `MODE=self` 则启动失败

2. **web 容器直接暴露 0.0.0.0:8889**
   - 当前宿主机可访问，但公网风险取决于网络拓扑
   - 无 HTTPS（HTTP 明文传输 session_token）
   - 缓解：dev compose 内部使用，外部访问需过 tailscale/caddy

3. **.env 文件明文密码（gitignore 内）**
   - DB_PASSWORD=***
   - DEFAULT_ADMIN_PASSWORD=lewellyn
   - REDIS_PASSWORD=***
   - 风险：若误 git add -f 或 push 到公网仓库 = 全暴露
   - 缓解：`.gitignore` 已配置；2026-04-19 `git filter-branch` 清除历史

**🟡 中**

4. **CSRF middleware 仍禁用**（`app/middleware/csrf.py`）
   - 依赖 session token header 认证，无 CSRF token
   - 风险：若浏览器可访问，攻击者可伪造 POST
   - 现状：self 模式无 CSRF 风险；team 模式需开启

5. **限流器已临时禁用**（`RateLimitMiddleware`）
   - 防止暴力破解已关闭
   - 现状：trust proxy 模式下可重新启用

6. **Webhook 端口 8084 未启用**（HMAC 验证代码就绪但服务未跑）
   - 无暴露 = 无风险

**🟢 低**

7. **审计日志完整**（EVENT_CRAWL_STARTED/COMPLETED/FAILED）
   - 490 条记录可查询
8. **URL 白名单 + InputSanitizer**：正常运行
9. **bcrypt 密码哈希**：正常
