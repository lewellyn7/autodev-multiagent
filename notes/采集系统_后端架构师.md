## 核心模块

### API 层 (app/api/)
- `routes.py` — 主 API 路由（项目、收藏、注释、预设、重复检测）
- `routes_n8n.py` — n8n 集成接口
- `api_server.py` — FastAPI 服务（POST /crawl, GET /status/{task_id}, GET /results/{task_id}, GET /stats）
- `auth` — session token 认证依赖

### 爬虫层 (app/crawlers/)
- `base.py` — BaseCrawler 基类
- `ccgp.py` — 重庆政府采购网采集器 V3
  - 支持三类信息：采购意向 / 采购公告 / 结果公告
  - 基于 Playwright 浏览器自动化
- `cqggzy.py` — 重庆公共资源交易网采集器

### 核心调度 (app/core/)
- `concurrency_scheduler.py` — 并发调度器（SafetyLevel 分级控制）
- `browser.py` — 浏览器引擎（Playwright + Stealth）
- `permissions.py` — 权限管理
- `predictive_scale.py` — 预测性扩缩容

### 数据模型 (app/models/)
- `TenderInfo` — 25 字段结构化数据
  - title, url, source_url, publish_date, business_type, info_type
  - matched_keywords, raw_data, status 等

### NLP (app/nlp/)
- `classifier.py` — 分类器
- `summarizer.py` — 摘要生成

### 安全 (app/security/)
- 审计日志 (audit)
- 分布式限速 (DistributedRateLimiter)
- CSRF 中间件

## 调度机制

- APScheduler BlockingScheduler
- 定时任务：每天 08:00 / 12:00 / 18:00 执行
- 独立 Docker 容器运行（与 Web 服务解耦）
- 采集结果写入 output/ 目录 + 数据库
- 审计日志覆盖采集开始/成功/失败

## 架构优缺点

### ✅ 优点
- 模块解耦清晰，API/爬虫/调度分离
- 并发控制机制完善（SafetyLevel 分级）
- 25 字段 TenderInfo 模型为 AI 特征提取奠定基础
- Docker Compose 全家桶部署完整
- 审计日志完整

### ⚠️ 待优化
- SQLite → PostgreSQL 迁移未完成
- TF-IDF 关键词匹配精度低（AI-INTELLIGENCE_ASSESSMENT.md）
- 无自动分类，靠爬虫 Hardcode
- 去重依赖 URL，相似项目不同链接会重复
- 无优先级机制，所有匹配项目平铺
- 无预测性告警（截标日期临近无提醒）
- 历史数据无法语义检索（pgvector 未充分利用）
