## 本次收尾完成项

### 1. 凭证硬化 (Security)
**问题**: `settings.py` 中 `DEFAULT_ADMIN_PASSWORD` 默认值为 `admin123`，存在安全风险。

**修复**:
```python
# 修复前
return os.getenv("DEFAULT_ADMIN_PASSWORD", "admin123")

# 修复后
pwd = os.getenv("DEFAULT_ADMIN_PASSWORD")
if not pwd:
    raise ValueError(
        "DEFAULT_ADMIN_PASSWORD environment variable is not set. "
        "Production deployment requires explicit admin password."
    )
return pwd
```

**影响**: 生产环境强制显式配置管理员密码，防止默认密码泄露风险。

---

### 2. pgvector HNSW 索引优化 (AI/Backend)
**问题**: 
- Qwen3-Embedding-4B 生成 2560 维向量
- pgvector IVFFlat/HNSW 索引上限 2000 维
- 之前数据迁移到 `vector_store_1024` (1024 维) 但新数据仍写入 `vector_store` (2560 维)

**修复**:
1. 新增 `VectorStoreServiceIndexed` 类，自动切片 2560→1024 维
2. 新采集数据优先写入 `vector_store_1024` 表 (HNSW 索引)
3. `vector_store` (2560 维) 保留原始数据用于向后兼容

**代码变更**:
- `app/services/vector_store.py`: 新增 `VectorStoreServiceIndexed` 类
- `main.py`: `_upsert_to_vector_store()` 改用 `get_vector_store_indexed()`

**验证**:
- `vector_store_1024` 表：59 条记录 (1024 维)
- HNSW 索引：`vector_store_1024_embedding_hnsw` (m=16, ef_construction=64)
- `/health` 返回 `backend: pgvector, total_vectors: 117`
